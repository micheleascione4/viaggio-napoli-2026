# Orbital Foundry

A native Android aerospace sandbox inspired by the accessibility of Spaceflight Simulator and the deeper aerospace gameplay of Juno: New Origins.

This is an original implementation. No game assets, code, or UI are copied.

## Current direction

**Easy to start:** assemble a stack and launch.

**Deep when wanted:** contracts, funds, science, technology, telemetry, orbital guidance, trajectory prediction and vehicle analysis.
